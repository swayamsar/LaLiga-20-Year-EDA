# LaLiga-20-Year-EDA

This project performs Exploratory Data Analysis (EDA) on 20 years of La Liga football statistics using Python and data visualization techniques.

## Objectives
- Analyze team performance trends
- Study goal-scoring patterns
- Compare club statistics across seasons
- Generate business intelligence insights from football data

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Key Insights
- Long-term performance comparison of clubs
- Seasonal goal distribution analysis
- Home vs away performance trends
- Statistical visualization of match outcomes
